矩阵与向量的乘法

Matrix-vector Multiplication
重点难点易错点

知识点

1) 核心恒等式：矩阵乘向量 = 矩阵各列的线性组合

Ax = b ⇔ x1 + x2 + ⋯ + xn =

即 Ax = x1a1 + x2a2 + ⋯ + xnan，其中 ai 是 A 的第 i 列。「方程组有解」与「b 能写成 A 的列的组合」是同一件事。

2) 定义条件（维度规则）

  • 只有当 向量的长度 = 矩阵的列数 时，Ax 才有定义。
  • Am×n · xn×1 = bm×1：结果向量的长度 = 矩阵的 行数。

3) 运算性质（设 A, B 均为 m×n，w, v ∈ ℝn，c 为标量）

  • A(w + v) = Aw + Av
  • A(cw) = c(Aw) = (cA)w
  • (A + B)w = Aw + Bw
  • Iw = w（I 为 n×n 单位阵）

以及最关键的一条：若 Aw = Bw 对所有 w ∈ ℝn 都成立，则 A = B。

4) 证明工具：标准向量 ei。设 ei ∈ ℝn 是第 i 个分量为 1、其余为 0 的向量，则 Aei = ai，即 A 的第 i 列。

取 w = e1：Ae1 = a1，Be1 = b1，由 Ae1 = Be1 ⇒ a1 = b1
↓
依次取 e2, e3, …, en ⇒ a2 = b2, …, an = bn
↓
每一列都相同 ⇒ A = B
🎯 重点
  • 会算 Ax 的 两种方法：① 行点积法（bi = 第 i 行 · x）；② 列组合法（x 的分量作为 A 各列的系数）。
  • 维度规则 (m×n)(n×1) = (m×1)，用来判断乘法是否有意义。
  • 四条运算性质 +「对所有 w 成立 ⇒ A = B」。
🧩 难点
  • 「对所有 w ∈ ℝn 都有 Aw = Bw ⇒ A = B」的证明：要想到用 标准向量 ei 把矩阵“按列拆开”逐列比较。
  • 把 Ax 同时看成“行点积”与“列的组合”，并能在两种视角间自由切换（模块 4、6 都要用“列的组合”视角）。
⚠️ 易错点
  • 维度不匹配还硬算：A 的列数必须等于 x 的分量个数，结果长度等于 A 的行数。
  • 把矩阵乘向量当成“对应元素相乘”（那不是 Ax）。
  • 只验证几个特殊的 w 就断言 A = B —— 必须是 所有 w 都成立。
  • Iw = w 中的单位阵 I 必须是 n×n（与 w 同阶），写成别的阶数就不成立。

02

消元法与回代

Elimination & Back Substitution
重点易错点

知识点

1) 等价方程组：两个线性方程组 等价 ⇔ 它们的 解集完全相同。消元的本质就是用等价变形把方程组化得越来越“简单”，但解集始终不变。

2) 三种初等行变换（Elementary Row Operations）

类型记法说明
① 互换（Interchange）Ri ↔ Rj交换两行的位置
② 缩放（Scaling）kRi → Ri，k ≠ 0某一行乘以 非零 常数
③ 行加（Row Addition）Ri + kRj → Ri，i ≠ j把另一行的倍数加到某一行

这三类操作都是 可逆 的，且逆操作仍是同一类型的行操作 —— 这正是“解集不变”的根本原因。

3) 讲义原例（Elimination and Back Substitution）

eq.(2)×3 ⟶ eq.(2)+eq.(1)×(−1) ⟶
eq.(1)−eq.(2) 后 ×1/3 ⟶ 互换两行 ⟶

回代（Back Substitution）：由 x1 = 11/4 代回第一式 x1 + 3x2 = 2，得 x2 = −1/4。

🎯 重点
  • 「等价 = 解集相同」，三种初等行变换都能产生等价方程组。
  • 三种行变换的 记法与写法：Ri ↔ Rj、kRi → Ri、Ri + kRj → Ri。
  • 解题两步走：消元（化成阶梯形 / 化简阶梯形）→ 回代（从最后一行往上解）。
🧩 难点
  • 为什么缩放倍数 k 必须 非零：k = 0 会把整行抹成 0，等于丢掉一条方程，解集被放大（不再等价）。
  • 为什么只能做 行 变换：对方程组来说，交换 / 缩放列相当于改变未知数的含义，一般会改变解集。
  • 把「用行变换解方程」与「用矩阵语言解方程」对应起来（见模块 3）。
⚠️ 易错点
  • 用 Ri → 0·Ri “消掉”某行 → 解集变大，属于非法操作。
  • 只对系数做变换而忘记 常数项（增广列）：整行要一起变，不能漏最后一列。
  • 做列变换（如 C2 → 2C2、交换两列）—— 那不等价于原方程组。
  • 回代时符号写错，或把 x1、x2 的位置对应错。

  1. R2 → 0·R2
  2. R1 → R1 − 3R2

增广矩阵与高斯消元（REF / RREF）

Augmented Matrix & Gaussian Elimination
重点难点易错点

知识点

1) 方程组 ⇔ Ax = b ⇔ 增广矩阵：把常数项 b 作为最后一列接在系数矩阵右边，记作 [A|b]，尺寸为 m×(n+1)。

=  [A | b]，m×(n+1)

2) 主元（leading entry / pivot）：若某一行不全为 0，则该行 最左边的非零元 称为这一行的主元。

3) 行阶梯形（Row Echelon Form, REF）：

  • 每个非零行都位于所有零行 之上；
  • 主元呈阶梯状：下面各行的主元都在上一行主元的右边。

4) 化简行阶梯形（Reduced Row Echelon Form, RREF）：在 REF 的基础上，主元所在列都是标准向量，即主元 = 1，且该列其余元素全为 0。RREF 是 唯一 的。

高斯消元（Gaussian Elimination） 就是用初等行变换求矩阵 RREF 的算法。

🎯 重点
  • 能把方程组写成增广矩阵，并用行变换一步步化简。
  • 能判断一个矩阵是 REF 还是 RREF：零行在底 + 主元右移 + 主元列为标准向量。
  • RREF 可以“直接读出”解（每个主元列对应的变量 = 该行最后一列的常数）。
🧩 难点
  • 理解 RREF 的唯一性（与 REF 不唯一相对）。
  • 区分 REF 与 RREF：REF 只要求“阶梯”，RREF 还要求主元列干净。
  • 消元时判断“先处理哪一列、用哪一行做主元”会让计算更省力。
⚠️ 易错点
  • 把“任意非零元”都当主元 —— 主元是每行 最左边 的非零元，每行只有一个。
  • 在 REF 中要求主元必须为 1（不必）；反过来在 RREF 中主元列还留着别的非零数（不合格）。
  • 零行没有放到最底下。
  • 消元过程中动了某一列（列不能乘 k，也不能换列）。
  • 只写 RREF 而漏掉“零行的个数”，导致后面算秩时出错。

04

RREF 与线性组合（列对应原理）

RREF v.s. Linear Combination
重点难点易错点

知识点

1) 列对应原理（Column Correspondence Principle）：设 A = [a1, …, an] 的 RREF 是 R = [r1, …, rn]。

  • 初等行变换 不改变非零行的个数。
  • 若 ai 是 A 其他列的组合（系数为 c），则 ri 也是 R 对应列以 相同系数 c 的组合；反之亦然。
  • 若 [A|b] 的 RREF 为 [R|b′]，则 Ax = b 与 Rx = b′ 解集相同；Ax = 0 与 Rx = 0 也解集相同。

一句话：行变换改变的是行之间的关系，保持的是列之间的关系。（题目里说的“non-zero row”指对应的方程是真正起作用的，而不是物理上全为 0 的行。）

2) 最关键的对比表（讲义 Original Matrix v.s. RREF）

行（Rows）列（Columns）
关系是否保持❌ 行之间的关系 改变✔ 列之间的关系 不变
张成空间✔ 行的张成空间 相同❌ 列的张成空间 不同

② 的验证：c1 = (1,5)，c2 = (2,5)，c1 + 2c2 = (1+4, 5+10) = (5,15) = c3 ✔

4) 讲义例题（E.g.3）

A = ，其 RREF 为 R =

黄色列（第 1、3、4 列）是主元列。R 中的非主元列都是主元列的线性组合：r2 = 2r1，r5 = r4 − r1，r6 = 2r4 − 3r3 − 5r1。由列对应原理，A 的列满足完全相同的系数关系：a2 = 2a1，a5 = a4 − a1，a6 = 2a4 − 3a3 − 5a1。

同时，Ax = 0 有无穷多解，例如 x1 = (−2, 1, 0, 0, 0, 0)T（对应 −2a1 + a2 = 0）与 x2 = (1, 0, 0, −1, 1, 0)T（对应 a1 − a4 + a5 = 0）。

🎯 重点
  • 列之间的线性关系在行变换下 完全不变（系数一一对应）—— 这是后面求最大无关组、解方程组的理论基础。
  • 行 / 列对比表：行关系变、行空间不变；列关系不变、列空间变。
  • 会用 R 中“非主元列 = 主元列的组合”推出 A 中对应的关系，从而构造 Ax = 0 的解。
🧩 难点
  • “行的张成空间不变，但列的张成空间改变”这组对比非常反直觉，要结合“行变换 = 行向量的线性组合重新组装”来理解。
  • 把“列关系不变”与“Ax = 0 的解不变”联系起来（解向量的分量就是列之间的组合系数）。
⚠️ 易错点
  • 以为 列空间（span of columns）也不变 —— 错，列空间通常会变；不变的是列之间的 关系。
  • 把 R 的列直接用做 A 的列空间的基 —— 应该用 A 中与 R 主元列 位置对应 的那些列。
  • 只记结论不看列号：系数的对应必须严格按列号一一对应，不能乱配。
  • 把“行变换不改变非零行个数”误记成“不改变非零元素个数”。

05

RREF 与线性无关

RREF v.s. Independent
重点难点易错点

知识点

1) 主元列 = 最大线性无关组：在 R 中，主元列（上例的 r1, r3, r4）线性无关；而每一个 非主元列 都是它前面主元列的线性组合。这个“哪些列无关”的结论可以原样搬回 A。

2) 判据：A 的列向量组线性无关 ⇔ A 的 RREF 中 每一列都有主元（不存在非主元列）。

3) 三种典型形状（讲义 RREF v.s. Independent）：

矩阵形状与假设RREF 的形式结论
An×n 方阵，所有列线性无关 = In RREF 就是单位阵，秩 = n
Am×n，m > n，所有列线性无关 上面 n 行为 In，下面 m−n 行全为 0 每列都有主元，秩 = n（满列秩）
Am×n，m < n 最多 m 个主元，至少有 n−m 个非主元列 不可能所有列都无关：ℝm 中超过 m 个向量必线性相关

推导思路：RREF 中主元个数 ≤ 行数 m，而“所有列无关”要求主元个数 = 列数 n，于是必须 n ≤ m。

🎯 重点
  • 主元列 ⇔ 最大线性无关组；非主元列 ⇔ 对应 自由变量。
  • “列线性无关 ⇔ 每一列都有主元 ⇔ RREF 中没有非主元列”。
  • 常见形状结论：方阵列无关 ➜ RREF = In；m > n ➜ 上 In、下全 0。
🧩 难点
  • 把“主元列构成一个最大无关组”与“列空间的张成”结合起来：最大无关组不唯一，但 个数（= 秩）唯一。
  • 理解为什么 m < n 时列一定相关（主元 ≤ m < n）。
  • “非主元列是 前面 主元列的组合”这一句里的“前面”很关键（由 RREF 的阶梯结构保证）。
⚠️ 易错点
  • “矩阵里 0 很多 ⇒ 一定相关”是错的，必须看主元个数。
  • 以为非主元列可以直接丢掉不看 —— 它不能“被单独保留成无关”，但它的存在说明该列可由前面的主元列表示。
  • 漏掉“列数 > 行数 ⇒ 必相关”这条最常考的结论。
  • 把“没有非主元列（列无关）”与“没有零行（行张满 ℝm）”混为一谈，这两件事完全不同。

06

RREF 与秩（解的结构与相容性）

RREF v.s. Rank
重点难点易错点

知识点

1) 秩与零化度

  • 秩 r(A)：A 中最大线性无关 列 的个数。
  • r(A) = r(R) = 主元列的个数 = R 中非零行的个数。
  • 零化度（Nullity）= n − r(A)，其中 n 是 列数（注意不是行数）。
  • 满秩（full rank）：r(A) = min{m, n}。

2) 变量分类：若方程组有无穷多解，自由变量（free variables） 对应 没有主元的列，其余变量称为 基本变量（basic variables）。

3) 无解的判据：给定 Ax = b，若 b 不在 A 的列张成的空间中（b ∉ Span{a1, …, an}），则方程组不相容（无解）。此时 [A|b] 的 RREF 形如：

[R|b′] = (d ≠ 0)  ⇔  r(A) ≠ r([A|b])

也就是出现了形如「0 = d」的矛盾行：只有最后一列非零。

4) 解的结构（三分类）

情形判据解的情况
无解r(A) ≠ r([A|b])[R|b′] 出现 (0 … 0 | d)，d ≠ 0
唯一解r(A) = r([A|b]) = n有解且无自由变量
无穷多解r(A) = r([A|b]) < n有解且有 n − r(A) 个自由变量

5) 相容性等价链（对每个 b 都有解）

Ax = b 对每个 b 都相容
⇕
每个 b 都是 A 的列的线性组合
⇕
[R|b′] 不能 有一行只在最后一列非零（这蕴含 m ≤ n）
⇕
R 不能有零行
⇕
A 的每一行都有主元
⇕
r(A) = m，且每个 b ∈ Span{a1, …, an}
⇕
Span{a1, …, an} = ℝm，即 m 个线性无关的向量可以张满 ℝm
🎯 重点
  • 会算秩：数主元列（等价于数 RREF 的非零行）。
  • 零化度 = n − r(A)；自由变量个数 = 非主元列个数。
  • 用 r(A) 与 r([A|b]) 判断无解；用 r(A) 与 n 判断唯一 / 无穷多解。
  • 相容性等价链（尤其是 r(A) = m ⇔ R 无零行 ⇔ 列张满 ℝm）。
🧩 难点
  • 把「R 有零行」与「存在无解的 b」正确挂钩：R 有零行只是说 存在 使系统无解的 b，并不代表某个具体的 b 一定无解。
  • 理解“对每个 b 都相容 ⇒ m ≤ n”（列数不能少于行数）。
  • 区分“主元个数”与“行数”这两个不同的量。
⚠️ 易错点
  • 零化度写成 m − r(A) —— 应为 n − r(A)。
  • 只看 A 的 RREF 就判断有无解 —— 判断相容性必须看 增广矩阵 [A|b] 的 RREF。
  • “方程个数 ≥ 未知数个数 ⇒ 一定有解”是错的（m ≥ n 不保证相容）。
  • 把“某个 b 有解”与“每个 b 都有解”混为一谈。
  • “R 有零行 ⇒ 系统无解”也是错的（那要看具体的 b）。

E13×2 矩阵能否让 Ax = b 对每个 b ∈ ℝ3 都有解？
答案：不能

要让每个 b 都有解，需要 r(A) = m = 3（RREF 无零行）。但主元个数 ≤ 列数 = 2，所以 r(A) ≤ 2 < 3，RREF 至少有一个零行 ➜ 存在某个 b 使系统无解。

等价说法：ℝ3 中 2 个向量不可能张满 ℝ3。这也印证了“对每个 b 相容 ⇒ m ≤ n”。

E2m > n 且列全无关时，RREF 长什么样？
答案：上面 n 行是 In，下面 m−n 行全为 0

理由：列全无关 ⇒ 每列都有主元 ⇒ 共有 n 个主元，必须恰好占据前 n 行（每行一个，且呈阶梯形），其余 m−n 行只能是零行。此时 r(A) = n = min{m, n}，是满秩。

E3判断：「初等行变换保持 A 的列空间不变。」
答案：错误

行变换保持的是 列之间的线性关系（列对应原理），而列空间（Span of columns）一般会 改变。保持不变的张成空间是 行空间。

例子：A = (1 2 5; 2 −1 0) 做 R2 ← R2 + 3R1 得 (1 2 5; 5 5 15)，此时 A 的第 1 列 (1,2)T 已不在新矩阵的列空间中。

💡 记忆：行空间不变、列关系不变；行关系改变、列空间改变。

E44×5 矩阵，r(A) = 4，Ax = b 是否对每个 b ∈ ℝ4 都有解？
答案：是，对每个 b ∈ ℝ4 都有解；且解有无穷多个

r(A) = 4 = m（行数）⇒ 由相容性等价链：R 没有零行 ⇒ A 每一行都有主元 ⇒ Span{a1, …, a5} = ℝ4，所以每个 b 都相容。

又因为 r(A) = 4 < n = 5，存在 5 − 4 = 1 个自由变量 ➜ 一旦有解就有无穷多解（对应齐次方程 Ax = 0 有非零解，解空间维数为 1）。

💡 注意这里 m ≤ n（4 ≤ 5）是必要条件，和 E1 正好形成对照。
