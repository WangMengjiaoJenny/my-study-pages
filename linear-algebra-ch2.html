知识点 1 / Knowledge Point 1

矩阵-向量乘法 Matrix-vector Multiplication

Ax = b

重点 难点 易错点

核心内容

Ax = x1·a1 + x2·a2 + ⋯ + xn·an = b
  • 定义条件（易错）：Am×n 乘向量 x 时，x 的长度必须等于 A 的列数 n（即 x ∈ Rn），结果 b ∈ Rm。
  • 线性组合观点（重点）：Ax 可理解为「A 的各列以 x 的分量为系数的线性组合」。
  • 运算性质：
    A(w+v) = Aw + Av
    A(cw) = c(Aw) = (cA)w
    (A+B)w = Aw + Bw   ·   Inw = w
  • 提取列技巧：Aei = ai（第 i 个标准单位向量乘 A，得到 A 的第 i 列）。
  • 判定 A=B：若对所有 w ∈ Rn 都有 Aw = Bw，则 A = B（证明时取 w=ei 逐列比对）。
重点

把 Ax 记住是「列的线性组合」而不是「逐行点积」，这是后续理解列空间、线性相关、秩的关键直觉。

难点

「若对所有 w 都有 Aw=Bw，则 A=B」的证明：分别取标准向量 e1,…,en，由 Aei=ai、Bei=bi 推出 ai=bi。

易错点
  • 维度不匹配：Am×n 只能乘 n 维向量；写成 A3×4 乘 3 维向量是错误的。
  • 忘掉 Aei = ai 这个「取列」技巧，导致证明类题目卡壳。
  • 混淆 A(cw) 与 (cA)w：两者相等，但 c(Aw) 是把「标量提出到最前面」。

练习题

Q1

设 1234，x = [5, 6]T。用「列的线性组合」计算 Ax。

答案：Ax = [17, 39]T

解析：Ax = 5·[1,3]T + 6·[2,4]T = [5+12, 15+24]T = [17, 39]T。体会「列的组合」而非「行点积」。

Q2

若 A 是 3×4 矩阵，要使 Ax 有定义，x 应为几维向量？结果 Ax 又是几维？

答案：x ∈ R4（4 维），结果 Ax ∈ R3（3 维）。

解析：向量长度必须等于矩阵列数（4）；结果维度等于矩阵行数（3）。

知识点 2 / Knowledge Point 2

线性方程组的消元与等价变换 Elimination & Equivalent Systems

Equivalent systems · Augmented matrix · Back substitution

重点 易错点

核心内容

  • 等价方程组：解集完全相同的两个方程组互称等价。
  • 三种初等行运算（产生等价方程组）：
    ① 换行  Ri ↔ Rj
    ② 倍乘  kRi → Ri  (k ≠ 0)
    ③ 倍加  Ri + kRj → Ri  (i ≠ j)
  • 可逆性：三种行运算都可逆，且逆变换是同类运算，因此不改变解集。
  • 增广矩阵：把系数矩阵 A 和常数列 b 拼成 [A | b]（大小 m×(n+1)）。
  • 回代：消元成上三角后，从下往上代入求解。
重点

三种行运算（换行 / 倍乘 / 倍加）是贯穿全章的工具，务必记牢它们的记号与「可逆」特性。

易错点
  • 倍乘必须 k ≠ 0：用「某行 ×0」会丢失方程信息、改变解集，是高频陷阱。
  • 「等价」指解集相同，不是「方程长得一样」。
  • 增广矩阵写漏常数列 b（只写 A 而不写 [A|b]）。

练习题

Q1

下列哪个操作不能保证方程组解集不变？

  • A. 交换两行
  • B. 某一行乘以 0
  • C. 某一行乘以 3
  • D. 某一行加上另一行的 2 倍

答案：B

解析：乘以 0 不可逆（丢失信息），会改变解集；其余三项都是合法的初等行运算。

Q2

把方程组写成增广矩阵：

x1 + 3x2 = 2；  3x1 + x2 = 8

答案：132318

解析：系数矩阵加常数列，即 [1 3 | 2; 3 1 | 8]，虚线左侧是 A，右侧是 b。

知识点 3 / Knowledge Point 3

行阶梯形 REF 与简化行阶梯形 RREF

Row Echelon Form · Reduced Row Echelon Form · Gaussian Elimination

重点 难点 易错点

核心内容

  • 主元（pivot / leading entry）：某非零行最左边的非零元素。
  • REF（行阶梯形）： ① 非零行都在零行之上；② 主元呈阶梯状（每行的主元都在下一行主元的左侧）。
  • RREF（简化行阶梯形）：在 REF 基础上，主元所在列是标准向量（主元 = 1，且该列其余全为 0）。RREF 是唯一的。
  • 高斯消元法：求 RREF 的算法（消元 → 归一 → 回代消去上方元素）。
重点

RREF 的唯一性是本章最重要的结论之一：同一矩阵无论怎么消元，最终 RREF 唯一。

难点

区分 REF 与 RREF：REF 只要求「阶梯 + 主元在上方」，允许主元上方还有非零数；RREF 还要求主元列是标准向量。

易错点
  • 把 REF 误判成 RREF（忘了主元列上方必须全为 0）。
  • 认为 REF 也唯一——其实 REF 不唯一，只有 RREF 唯一。
  • 主元不一定等于 1（REF 中主元可以是任意非零数，只有 RREF 强制主元为 1）。

练习题

Q1

判断矩阵 123014001 是 REF、RREF，还是两者都不是？

答案：是 REF，但不是 RREF。

解析：主元 1,1,1 呈阶梯排列、零行在下 → 满足 REF；但主元列上方有非零元素（2、3、4）→ 不满足 RREF。

Q2

关于 RREF 与 REF，下列说法正确的是？

  • A. RREF 唯一，REF 也唯一
  • B. RREF 唯一，REF 不唯一
  • C. RREF 不唯一，REF 唯一
  • D. 两者都不唯一

答案：B

解析：RREF 唯一；REF 可因消元顺序不同而不同，不唯一。

知识点 4 / Knowledge Point 4

RREF 与列关系 Column Correspondence Principle

Row operations preserve column relations

重点 难点 易错点

核心内容

  • 列对应原理：设 A = [a1,…,an]，RREF 为 R = [r1,…,rn]。
    • 若 ai 是其他列的线性组合，则 ri 是对应列的同系数线性组合；反之亦然。
    • 增广矩阵 [A|b] 的 RREF 为 [R|b′]，且 Ax=b 与 Rx=b′ 同解。
  • 行与列的区别（核心结论）：
    对象线性关系span（张成）
    行被改变不变
    列不变被改变
重点

行变换保持列之间的线性关系（列关系不变），这是用 RREF 判断列相关/独立的根据。

难点

记住「行的 span 不变、列的关系不变」这组「十字交叉」结论，容易记反。

易错点
  • 把「行关系」和「列关系」搞混：行变换改变的是行之间的关系，不改变列之间的关系。
  • 误以为列的 span 也不变——列的 span 会变（行变换后列向量本身变了）。

练习题

Q1

A 经初等行变换得到 R。已知 R 的第 3 列 r3 = r1 + 2r2，则 A 的第 3 列 a3 = ?

答案：a3 = a1 + 2a2

解析：列对应原理——列之间的线性关系（含系数）在行变换下保持不变。

Q2

对矩阵做初等行变换后，下列哪一项不变？

  • A. 列之间的线性关系
  • B. 行之间的线性关系
  • C. 列的 span
  • D. 矩阵所有元素

答案：A

解析：行变换保持列关系不变；行的关系会变、列的 span 会变、元素当然也变。

知识点 5 / Knowledge Point 5

RREF 与线性无关 RREF & Linear Independence

Pivot columns are independent

重点 难点 易错点

核心内容

  • 主元列线性无关；非主元列是前面主元列的线性组合。
  • 定理：Rm 中多于 m 个向量必线性相关（即 m < n 时，Am×n 的列不可能全部独立）。
  • 方阵情形：An×n 全部列无关 ⟺ RREF = In（单位阵）。
  • 高瘦矩阵：Am×n（m > n）全部列无关 ⟺ RREF 形如 In0（上方单位阵、下方零行）。
重点

判断列是否线性相关，只需看 RREF：主元列 ↔ 无关，非主元列是主元列的线性组合。

难点

「多于 m 个向量在 Rm 中必相关」这一结论，用来解释为何 m < n 时列一定相关。

易错点
  • 以为「非主元列」之间也一定无关——其实非主元列正是主元列的线性组合，必然相关。
  • 主元列不一定对应原矩阵 A 中「编号相同的列」独立吗？—— 会独立，但列关系与 R 一一对应，注意别弄错列的下标。

练习题

Q1

5 个向量都位于 R3 中，它们能否线性无关？为什么？

答案：不能。

解析：R3 中多于 3 个向量必线性相关（5 > 3）。更一般地，Rm 中超过 m 个向量必相关。

Q2

3×3 方阵 A 的三列线性无关，则 A 的 RREF 是什么？

答案：3×3 单位矩阵 I3。

解析：三列无关 → 3 个主元列 → 无自由变量、无零行 → RREF 的每一列都是标准向量，即单位阵。

知识点 6 / Knowledge Point 6

RREF 与秩 Rank

Rank · Nullity · Full rank · Consistency

重点 难点 易错点

核心内容

  • 秩的定义：r(A) = Am×n 中线性无关列的最大数目。
  • 求秩：r(A) = r(R) = 主元列数 = 非零行数。
  • 零空间维数（Nullity）：Nullity = n − r(A)（列数 − 秩）。
  • 满秩：r(A) = min{m, n}。
  • 自由变量与基本变量：无主元的列对应自由变量，其余是基本变量。
  • 一致性判定：Ax=b 不一致 ⟺ [A|b] 的 RREF 出现形如 [0 … 0 | d]（d≠0）的行 ⟺ r(A) ≠ r([A|b])。
  • 对任意 b 都一致：⟺ r(A) = m ⟺ R 无零行 ⟺ 每行都有主元 ⟺ 列张成整个 Rm。
重点

r(A) = 主元列数 = 非零行数，是「数主元」求秩的快捷方法；一致性看 r(A) 是否等于 r([A|b])。

难点

「对任意 b 都一致 ⟺ r(A)=m」这条等价链（课件第 27 页），是概念题的高频考点。

易错点
  • Nullity = n − r(A)（是「列数」减秩），误用成「行数 m 减秩」。
  • 把 r(A) 与「矩阵列数」或「行数」混淆。
  • 看到 [0…0 | d≠0] 行却不判不一致——这行代表矛盾方程 0 = d。

练习题

Q1

若 A 是 4×6 矩阵，且 r(A) = 3，求 Nullity。

答案：Nullity = 3

解析：Nullity = n − r(A) = 6 − 3 = 3。

Q2

增广矩阵 [A|b] 的 RREF 出现一行 [0 0 0 | 5]，方程组 Ax=b 是否一致？

答案：不一致（无解）。

解析：该行表示 0=5，矛盾；此时 r(A) < r([A|b])，故方程组不一致。
