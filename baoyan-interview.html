宣讲会开篇引用中央精神：培养大批卓越工程师被作为重要任务——"要努力建设一支爱党报国、敬业奉献、具有突出技术创新能力、善于解决复杂工程问题的工程师队伍。要调动好高校和企业两方面的积极性，实现产学研深度融合。"（2021 年 9 月中央人才工作会议）

2022 年 9 月 27 日，教育部、国资委联合召开卓越工程师培养工作推进会，开启建设国家卓越工程师学院。会议指出新时代卓越工程师需要实现"三个根本转变"：

维度传统模式改革方向

这三条转变直接决定了面试的提问方式：老师不会只考你"背没背下来"，而会追问你"用这个知识解决过什么问题"。

面试可用：被问到"你为什么适合读工程硕博士"时，"两扎实 + 三突出"就是现成的答题框架。

H3通信专业题：企业专家可能怎么问？重点
企业专家最常问的 8 个方向（每题准备 60 秒版）
  • 链路预算：从发射功率到接收灵敏度，中间有哪些损耗项？为什么要留余量？
  • 调制与编码：QPSK 与 16QAM 怎么选？LDPC/Polar 解决什么问题？
  • 同步：载波同步、位同步、帧同步分别在做什么？失步会怎样？
  • 多径与均衡：频率选择性衰落怎么产生？OFDM + CP 为什么能简化均衡？
  • MIMO：分集增益和复用增益的区别，大规模 MIMO 的工程难点在哪。
  • 射频与天线：阻抗匹配为什么重要？驻波比、增益、方向图各是什么概念？
  • 光通信：光模块的关键指标（速率、功耗、消光比、灵敏度），800G 的散热与功耗挑战。
  • 协议与系统：TCP/IP 与无线协议栈的差异，实时性怎么保证。

💡 答题结构：先给结论 → 再讲物理/数学原因 → 最后给一个工程例子。只讲公式推导会被认为"没做过工程"。

专业知识（10 题）

先自己说一遍，再点开要点
A1采样定理是什么？它的物理意义和前提条件？重点
要点
  • 结论：对最高频率为 fmax 的带限信号，若采样频率 fs ≥ 2fmax，可用理想低通滤波无失真恢复原信号。2fmax 称为奈奎斯特频率。
  • 物理意义：时域采样对应频域周期性延拓，周期为 fs；只要延拓后的频谱不重叠，就能滤出原频谱。
  • 前提：信号必须带限（现实中不存在严格带限信号），所以要先用抗混叠滤波器。
  • 追问「fs < 2fmax 会怎样」：频谱混叠（aliasing），高频折叠到低频且不可逆。
A2写出香农公式，并说明如何提高信道容量。重点
要点

C = B log2(1 + S/N) bit/s

  • 三条途径：增大带宽 B、提高信噪比 S/N、提高频谱效率（更好的调制与编码）。
  • 关键理解：B 与 S/N 不是独立的——带宽变大，噪声功率 N = N0B 也变大，所以 B → ∞ 时容量趋于 1.44S/N0 的极限，存在上限。
  • 工程手段：大规模 MIMO、高阶调制、信道编码（LDPC/Polar）、自适应调制编码 AMC。
A3BPSK、QPSK、16QAM 如何取舍？重点
要点
  • 本质是频谱效率与抗噪性能的权衡：BPSK 1 bit/符号、QPSK 2 bit/符号、16QAM 4 bit/符号。
  • 阶数越高 → 星座点越密 → 相同平均功率下最小欧氏距离越小 → 误码率性能越差，需要更高信噪比。
  • 结论：信道差时用低阶调制（BPSK/QPSK），信道好时用高阶调制（16/64/256QAM）——这就是自适应调制编码的动机。
  • 追问「QPSK 与 4QAM 的关系」：在矩形星座下二者等价（都是 2 bit/符号）。
A4什么是多径衰落？OFDM 为什么能对抗多径？难点
要点
  • 多径衰落：信号经不同路径到达接收端，各路径时延/相位不同，叠加后幅度随机起伏（频率选择性衰落）。
  • 时域表现：时延扩展 → 产生符号间干扰 ISI。频域表现：相干带宽 Bc ≈ 1/时延扩展。
  • OFDM 思路：把高速串行数据分成 N 路低速子载波，符号周期变长 → ISI 大幅减小；加循环前缀 CP 把线性卷积变成循环卷积，从而只要单抽头均衡。
  • 追问「CP 的代价」：牺牲约 Tcp/(T+Tcp) 的频谱效率；CP 长度须大于最大时延扩展。
A5信源编码和信道编码有什么本质区别？重点
要点
  • 信源编码：压缩，目的是减少冗余、提高有效性。代表：Huffman、算术编码、变换编码（JPEG/MP3）。
  • 信道编码：加冗余，目的是纠检错、提高可靠性。代表：卷积码、Turbo、LDPC、Polar。
  • 一句话对偶："信源编码去冗余，信道编码加冗余"——它们的目标正好相反，但因为作用位置不同而同时存在。
  • 追问「香农第二定理告诉我们什么」：只要 R < C，就存在编码使误码率任意小——它保证了信道编码的存在性，但没告诉我们怎么构造（LDPC/Polar 就是逼近这个极限的成果）。
A6MIMO 的增益从哪里来？难点
要点
  • 空间分集增益：多天线接收多条独立衰落副本，降低中断概率（如 Alamouti 空时编码）。
  • 空间复用增益：在散射丰富的信道下开多条并行数据流，容量近似随 min(Nt, Nr) 线性增长。
  • 阵列增益 / 波束成形：相干合并提升信噪比，同时抑制干扰。
  • 大规模 MIMO（5G）：天线数远大于用户数，信道趋于正交，可用简单的线性检测（匹配滤波/MMSE）逼近最优。
A7判断一个系统是否为线性时不变系统，卷积的作用是什么？
要点
  • 线性 = 齐次性 + 可加性：T{ax1 + bx2} = aT{x1} + bT{x2}。
  • 时不变 = 输入时移 t0，输出只发生时移，波形不变。
  • 卷积的意义：任意输入可分解为冲激的加权叠加，LTI 系统输出 = 输入与冲激响应 h(t) 的卷积：y = x * h。
  • 时域卷积 = 频域相乘（Y = X·H），这是滤波器设计的理论基础。
  • 反例提醒："y(t) = x(2t)" 是线性的但不是时不变；"y = x2" 是时不变的但不是线性。
A8FIR 与 IIR 数字滤波器的区别与选择？
要点
  • FIR：只有零点，无反馈，可实现严格线性相位，绝对稳定；代价是阶数高、计算量大。
  • IIR：有极点，有反馈，用较少阶数获得陡峭过渡带；代价是相位非线性、可能不稳定、有极限环。
  • 选择原则：要求线性相位（如通信、音频）用 FIR；要求低运算量、指标不严格用 IIR。
  • 追问「线性相位为什么重要」：保证各频率分量时延一致，不产生波形失真。
A9列举 5G/6G 的关键技术，并挑一个你能讲透的。
要点
  • 5G 三大场景：eMBB（增强移动宽带）、mMTC（海量机器通信）、uRLLC（低时延高可靠）。
  • 关键技术：大规模 MIMO、毫米波、网络切片、边缘计算、灵活参数集（Numerology）、Polar/LDPC 码。
  • 6G 方向：通感一体化（ISAC）、智能超表面（RIS）、太赫兹、空天地一体化、内生 AI。
  • 答题技巧：列 5 个不如讲透 1 个。例如"网络切片"可以这样串起来：同一套物理设施上用虚拟化切出多张逻辑网络，各自独立的带宽/时延/可靠性指标，服务于 eMBB 与 uRLLC 两种完全不同的需求。
A10如果你被问到不会的通信专业问题怎么办？易错点
要点
  • 不要沉默，也不要硬编。标准应对话术："这块我掌握得不深，我先说我能确定的部分：……，剩下的我想应该是……，回去我会补上。"

  • 老师真正在看的是：你是否诚实、是否能拆解问题、是否知道自己的边界。

专业知识（11 题）

先自己说一遍，再点开要点
B1过拟合与欠拟合的表现和解决方法？重点
要点
  • 过拟合：训练误差低、验证误差高（高方差）。解决：数据增强、正则化（L1/L2）、Dropout、早停、减少参数量、集成。
  • 欠拟合：训练误差就很高（高偏差）。解决：增大模型容量、加特征、减正则、训练更久。
  • 常用判断：画学习曲线看训练/验证误差随数据量或迭代次数的走势。
  • 追问「Dropout 为什么能防过拟合」：训练时随机丢弃神经元，等效于训练大量子网络并做集成，同时破坏神经元间的共适应。
B2什么是偏差-方差分解？难点
要点
  • 期望泛化误差 = 偏差2 + 方差 + 不可约噪声。
  • 偏差：模型假设与真实函数的差距（拟合能力不足）；方差：对训练集扰动的敏感度（稳定性不足）。
  • 总误差呈 U 形：模型由简单变复杂，偏差下降、方差上升，中间存在最优复杂度。
  • 实践含义：Bagging 主要降方差，Boosting 主要降偏差。
B3梯度消失 / 爆炸是怎么产生的？ResNet 为什么有效？重点
要点
  • 反向传播是链式法则连乘：梯度包含若干雅可比矩阵连乘，若谱范数 < 1 则指数衰减（消失），> 1 则指数增长（爆炸）。
  • 诱因：深层网络、Sigmoid/Tanh 的饱和区导数接近 0、初始化不当。
  • ResNet 的关键是恒等跳连：梯度可以经 1 + f′(x) 的路径直接回传，恒等项保证梯度不会衰减到 0，因此能训练上百层。
  • 其他手段：ReLU/GELU、BatchNorm、合理初始化（Xavier/He）、梯度裁剪、LSTM 的门控机制。
B4BatchNorm 做了什么？训练和推理时有什么不同？难点
要点
  • 对每个 mini-batch 按通道做零均值单位方差归一化，再用可学习的 γ、β 做仿射恢复表达能力。
  • 训练时用当前 batch 的统计量；推理时用训练期间累积的滑动平均统计量。
  • 作用：缓解内部协变量偏移、允许更大学习率、加速收敛、有轻微正则效果。
  • 注意点：batch 很小时统计不稳（改用 LayerNorm / GroupNorm）；在 RNN、小 batch 检测任务中常常不合适。
B5推导一下反向传播（以一个两层网络为例）。难点
要点
  • 前向：z1 = W1x + b1，a1 = σ(z1)，z2 = W2a1 + b2，损失 L。
  • 反传核心：定义 δ = ∂L/∂z，则 ∂L/∂W = δ·aT，∂L/∂b = δ，δ前一 = (WTδ) ⊙ σ′(z)。
  • 说的顺序：先讲清楚"梯度沿计算图反向逐层相乘"，再写一层的公式，不要一上来就堆下标。
  • 加分句："整个过程可以用自动微分实现，框架里是反向模式 AD，代价与前向同阶。"
B6卷积相比全连接有什么优势？
要点
  • 局部连接：利用图像的局部相关性，参数量大幅下降。
  • 权值共享：同一卷积核在整张图上滑动，带来平移等变性并进一步减少参数。
  • 层次化特征：浅层边缘纹理、深层语义部件。
  • 追问「卷积核 3×3 堆叠为什么比 5×5 好」：两层 3×3 感受野等于 5×5，但参数更少（2×9 vs 25）且非线性更强。
B7Transformer 的自注意力公式与复杂度？重点
要点

Attention(Q,K,V) = softmax(QKT/√dk)V

  • 除以 √dk 是为了防止点积过大导致 softmax 饱和、梯度消失。
  • 复杂度：时间 O(n2d)，空间 O(n2)（注意力矩阵），所以长序列贵；改进方向是稀疏注意力、线性注意力、FlashAttention（IO 优化）。
  • 多头注意力：在不同子空间并行做注意力，拼接后再线性映射，增强表达能力。
  • 位置编码：自注意力本身无序，需要位置信息（正弦编码、可学习、RoPE）。
B8SGD、Momentum、Adam 有什么区别？
要点
  • SGD：每次用（一批）样本估梯度，噪声大、易在鞍点附近震荡，但泛化常更好。
  • Momentum：累积历史梯度做惯性，抑制震荡、加速沿一致方向的下降。
  • Adam：对每个参数自适应学习率，同时用一阶动量与二阶矩估计，收敛快，但有时泛化略差。
  • 实践：CV 常用 SGD+Momentum 调好学习率与余弦退火；NLP/Transformer 多用 Adam/AdamW。
B9类别不平衡时看什么指标？怎么处理？重点
要点
  • 不要只看 Accuracy（全猜多数类就有 99%）。看 Precision、Recall、F1、AUC-ROC、PR-AUC，极端不平衡时 PR 曲线更有参考价值。
  • 数据层面：重采样（过采样少数类 / 欠采样多数类）、SMOTE 合成少数类。
  • 算法层面：类别权重、Focal Loss 让难样本权重更大。
  • 追问「Precision 与 Recall 的取舍」：取决于业务代价——漏检代价高就提 Recall，误报代价高就提 Precision，通过阈值调节。
B10K-means 与 PCA 的原理、局限？
要点
  • K-means：最小化簇内平方误差，交替"分配点 → 更新质心"，本质是 EM 的特例。
  • K-means 局限：需预先指定 k（用肘部法 / 轮廓系数选）、对初值敏感（K-means++）、只适合近似球形且规模相近的簇、对异常值敏感。
  • PCA：对数据中心化后做特征分解/SVD，取最大特征值对应的方向作主成分；等价于在最小重构误差意义下做线性降维。
  • PCA 局限：只捕捉线性结构、对量纲敏感（要先标准化）、主成分的物理含义可能不清晰。
B11你了解大模型微调吗？（2026 年热门追问）重点
要点
  • 全参微调：效果上限高，但显存与存储成本大，每个任务存一份权重。
  • LoRA：冻结原权重，只在权重旁加低秩增量 ΔW = BA（B 是 d×r，A 是 r×k），只训练 A、B；参数量降到千分之几，可插拔切换。
  • 其他：Adapter、Prefix/Prompt Tuning、QLoRA（4bit 量化 + LoRA）。
  • 追问「什么时候不该微调」：知识更新类需求更适合 RAG（检索增强生成），因为微调容易过时且会引入幻觉。

Integrated circuits
重点难点

集成电路方向的面试特点：器件 + 电路 + 设计流程三条线都会问，动手做过的项目（流片、FPGA、EDA）会被反复追问。

专业知识（10 题）

先自己说一遍，再点开要点
C1MOSFET 的三个工作区如何划分？重点
要点
  • 条件（NMOS）：VGS < VTH 截止；VDS < VGS − VTH 线性/可变电阻区；VDS ≥ VGS − VTH 饱和区（沟道夹断）。
  • 饱和区电流：ID ≈ ½ μCox(W/L)(VGS − VTH)2——数字电路的开关状态与模拟放大都工作在饱和区。
  • 常考追问：为什么数字电路用饱和区？因为饱和区电流对 VDS 不敏感，输出接近理想电流源，增益高。
C2CMOS 反相器的功耗由哪几部分组成？重点
要点
  • 动态功耗（主要）：Pdyn = αCLVDD2f，来自负载电容充放电，其中 α 为翻转活动因子。
  • 短路功耗：翻转瞬间 NMOS/PMOS 同时导通形成直流通路，与输入上升下降时间和阈值有关。
  • 静态功耗：亚阈值漏电、栅氧隧穿漏电、反偏结漏电等。工艺越先进，静态功耗占比越高。
  • 降功耗手段：降低 VDD（平方收益最大）、时钟门控、多阈值电压设计、电源门控。
C3建立时间、保持时间与亚稳态是什么关系？难点
要点
  • 建立时间 tsu：时钟沿到来前数据必须稳定的最短时间；保持时间 th：时钟沿到来后数据必须保持的最短时间。
  • 违反 tsu 或 th，触发器可能进入亚稳态——输出既非 0 也非 1，在不确定时间后随机稳定。
  • 亚稳态不可消除，只能降低发生概率：用多级同步器（两级触发器）、降低时钟频率、异步 FIFO 做跨时钟域。
  • 追问「MTBF」：平均无故障时间，与同步级数、时钟频率、可用建立时间指数相关。
C4为什么数字电路用 CMOS 而不是 NMOS 逻辑？
要点
  • NMOS 传输强 0 弱 1（阈值损失），输出高电平会损失一个 VTH，且输出高时会持续有电流通路。
  • CMOS 用互补对管，稳态总有一管截止，静态电流几乎为零，输出轨到轨、噪声容限大、可低电压工作。
  • 代价：需要更多晶体管、输入电容更大、存在短路功耗。
  • 追问「为什么 CMOS 反相器的阈值电压设计在 VDD/2 附近」：让上升/下降时间对称，抗噪能力均衡。
C5摩尔定律遇到了什么问题？后摩尔时代有哪些技术路径？重点
要点
  • 问题：尺寸逼近物理极限，短沟道效应、漏电、热密度、"摩尔第二定律"（成本/晶体管不再持续下降）；EUV 光刻成本极高。
  • 器件路径：FinFET → GAA 纳米片 → CFET 堆叠。
  • 封装路径：2.5D/3D 封装、Chiplet（芯粒）、异构集成——用先进封装延续性能提升，这是目前最现实的路径。
  • 其他：新型存储器（MRAM/RRAM/PCM）、光互连、存算一体、碳基/二维材料器件。
C6数字 IC 设计的完整流程是什么？
要点
  • 前端：需求与架构 → RTL 设计（Verilog/SystemVerilog）→ 功能验证（UVM 仿真、形式验证）→ 逻辑综合（RTL → 门级网表）。
  • 后端：布局规划（floorplan）→ 标准单元放置（placement）→ 时钟树综合（CTS）→ 布线（routing）→ 时序收敛→ 物理验证（DRC/LVS/ERC）。
  • 签核：时序、功耗、IR drop、EM 检查 → 流片（tape-out）。
  • 测试：可测性设计（DFT/扫描链/ATPG）、封装与测试。
C7静态时序分析中的 setup slack 和 hold slack 怎么算？难点
要点
  • Setup slack = (要求到达时间) − (实际到达时间) = Tclk + tsu 相关项 − 数据路径延迟，要求 ≥ 0。
  • Hold slack = (实际到达时间) − (要求保持时间)，要求 ≥ 0。
  • 违反 setup：缩短数据路径（减少逻辑级数、优化布局）、降频、换更快的单元。违反 hold：插入延迟单元（buffer）加长路径。
  • 关键区别：setup 与时钟周期有关，hold 与时钟周期无关（这是常考的一句）。
C8理想运放的"虚短""虚断"怎么来的？
要点
  • 虚断：输入阻抗无穷大 ⇒ 流入两输入端的电流为 0。
  • 虚短：开环增益无穷大且输出有限 ⇒ 差模输入电压趋于 0，两输入端电位相等。
  • 成立的前提是负反馈——开环或正反馈时不能使用虚短。
  • 追问「实际运放的非理想因素」：失调电压、共模抑制比 CMRR、增益带宽积 GBW、压摆率 SR、输入失调与噪声。
C9SRAM、DRAM、Flash 的区别与用途？
要点
  • SRAM：6 管双稳态锁存，速度快、无需刷新、面积大、成本高 ⇒ 用于 CPU Cache、片上存储器。
  • DRAM：1T1C 电容存储，需周期性刷新、密度高、成本低、速度较慢 ⇒ 用于主存。
  • Flash：浮栅电荷存储，非易失 ⇒ 用于 SSD、嵌入式固件；写入速度慢、有擦写寿命限制。
  • 趋势：3D NAND 堆叠层数、DRAM 与逻辑的 3D 堆叠（HBM）缓解"存储墙"。
C10集成电路"卡脖子"环节有哪些？你怎么看？重点
要点
  • EDA 工具（Synopsys/Cadence/Siemens EDA 三家垄断）、高端光刻机（ASML EUV）、核心 IP（ARM、高速接口 IP）、材料（高纯硅片、光刻胶）、高端工艺。
  • 答题角度要"有层次"：设计工具 → 制造设备 → 材料 → IP 生态，逐层说明难点性质不同（工程积累 vs 物理极限 vs 生态锁定）。
  • 结合个人：说出你希望在哪个环节做贡献（如"EDA 的时序分析算法""器件建模""模拟电路设计"），比空谈口号更打动人。
  • 加分句：可以提到西电国家卓越工程师学院明确把集成电路列为重点领域，并已有"以实践成果替代学位论文"的授位案例。

科研与项目题库

Research & project
重点难点易错点

官方考核维度里"科研能力与创新意识"是单独一项，而这一项几乎全靠你讲项目来体现。下面 8 题是核心，每一题都要练成肌肉记忆。

核心模板：90 秒项目讲述法
  1. 问题背景（15 秒）：这是一个什么真实场景的需求 / 什么技术痛点。
  2. 我的角色（15 秒）：我负责哪一部分，团队多少人，我是主导还是参与。
  3. 技术方案（30 秒）：用了什么方法/架构/算法，为什么这么选，替代方案是什么。
  4. 可量化结果（20 秒）：指标提升多少、测试数据、代码量、通过率——必须有数字。
  5. 反思与延展（10 秒）：局限在哪，下一步想怎么做。

科研与项目（8 题）

建议对着手机录音练，回放听逻辑是否清楚
D1用 90 秒介绍你最重要的科研/项目经历。重点
要点
  • 严格按上面的五段模板讲，控制在 90 秒内。面试官最烦"讲了三分钟还没说到自己做了什么"。
  • 第一句话就要给结论："我在这个项目里主要负责 XX 模块，最后把 XX 指标从 A 提到了 B。"
  • 准备一个 30 秒版本（自我介绍时用）和一个 3 分钟版本（老师让你展开时用）。
  • 技术名词只说你真的懂的：说"用了 LSTM"就要能回答"为什么不用 Transformer"。
D2你在项目中最核心的贡献是什么？能量化吗？重点
要点
  • 用"动词 + 技术 + 数字"的结构：我设计/实现了 X，用 Y 方法，使 Z 提升了 N%。
  • 不要用"参与了""协助了"这种模糊词；也不要夸大成"我负责整个项目"。
  • 如果只是团队成员，就说清楚边界："我负责其中的数据预处理与模型调参，准确率从 86% 提升到 91%，主要负责 3 个模块里的 1 个。"
  • 把可验证的东西准备好：代码仓库、实验记录、测试报告截图（线上可准备共享屏幕）。
D3项目里遇到的最大困难是什么？怎么解决的？难点
要点
  • 用 STAR 结构：情境 Situation → 任务 Task → 行动 Action → 结果 Result。
  • 选一个技术性困难（不是"队友不配合"这种人际问题）：例如"训练不收敛""时序始终违例""信噪比上不去"。
  • 重点讲排查过程：你怎么定位、排除了哪些可能、试了哪些方案、最终为什么选这个。老师看的就是这个过程。
  • 结尾给结果与反思："这个问题让我养成了先做最小复现实验再改代码的习惯。"
D4如果重新做一次，你会怎么改进？易错点
要点
  • 这题考反思能力。千万别说"没什么可改进的"，那等于说没有思考。
  • 给两个层次：技术层面（换更好的方法/更严谨的实验设计）＋工程层面（提前做基线、版本管理、写好实验记录）。
  • 不要说"如果时间够就好了"这类空话，要说具体动作。
D5你的论文/专利的创新点在哪里？你个人贡献多少？重点
要点
  • 官方加分细则明确写："对于论文、专利及部分竞赛加分项目，学院会组织现场答辩，学生应对项目内容、自身贡献度以及项目之间的重复性做详细阐述。"
  • 准备三句话：① 别人怎么做的（现状）；② 我改了什么（创新点）；③ 好在哪（可量化的对比）。
  • 署名不是第一作者的，如实说明并聚焦自己的部分，别硬说成自己的成果。
  • 注意官方另有规定："学生与直系亲属或学历、职称、职务明显高于本人者合作的科研成果、竞赛奖项等仅作为参考，不纳入……评定指标体系。"
D6你读过哪些相关领域的论文？
要点
  • 只准备 2–3 篇能讲透的（最好是你要报的导师团队的工作或该领域经典综述），而不是列 20 篇。
  • 每篇准备三句：解决什么问题、核心方法、局限。
  • 如果确实没读过，老实说，然后补一句"我最近在看 XX 方向的综述"。临时编论文名是最危险的行为之一。
D7你的毕设准备做什么？和报考方向有什么关系？
要点
  • 把毕设选题主动靠向报考方向：通信方向可以做"基于 XX 的信道估计/调制识别"；AI 方向做"XX 场景下的检测/分类模型"；集成电路做"XX 电路模块设计/器件建模"。
  • 讲清三段：课题来源（导师课题/竞赛延续/企业需求）→ 要解决什么 → 预期指标。
  • 如果还没定，就给一个明确的方向 + 你已经查过的两篇文献，展示主动性。
D8你做过的实验失败过吗？怎么处理的？
要点
  • 一定要准备一个真实失败案例——研究生阶段失败是常态，老师想确认你扛得住。
  • 结构：失败现象 → 我如何做二分排查 → 找到根因 → 调整方案 → 结果。
  • 收尾句推荐："这次失败让我明白，先建立可靠的基线（baseline）再谈优化，比一上来就上复杂方法更有效。"

要点
  • 常见形式：老师用英文提问让你用英文回答；读一段专业短文让你复述；听写专业词汇或数字。
  • 准备方式：把 20 个专业核心词汇的英文+发音练熟（各方向不同，见下），再把自我介绍的英文版读 20 遍。
  • 听不清就大方请老师重复，比乱答好得多。
E7三个方向的核心专业英语词汇表。重点
考前必背 30 词
  • 通信/信号：modulation, demodulation, bandwidth, spectrum, signal-to-noise ratio, sampling, aliasing, channel estimation, fading, MIMO, orthogonal, filter, convolution.
  • 人工智能：neural network, convolutional, gradient descent, loss function, overfitting, regularization, attention, transformer, embedding, inference, training, dataset, label.
  • 集成电路：transistor, CMOS, threshold voltage, leakage current, layout, timing, clock, power consumption, fabrication, wafer, package, simulation, verification.
  • 练法：每个词能造一句与你项目相关的句子，比单纯背单词有用得多。
E8Tell me about your hometown / hobbies / a challenge you overcame.
要点
  • 这属于"破冰题"，答 4–6 句即可，不要长篇大论，也不要只说一个词。
  • 爱好最好能与专业挂钩（机器人、开源项目、硬件 DIY、跑马拉松体现毅力），但不要编造。
  • 准备一个"克服困难"的英文小故事（3 句），很多学校会反复用这题。

综合素质与思想政治

Overall quality
重点易错点

官方原文："思想政治素质和品德考核不合格者不予录取"。这一项通常不会单独考你政治理论，而是藏在这类问题里。

综合素质（9 题）

每题答 1–2 分钟，态度比辞藻重要
F1为什么选择推免而不是出国或就业？重点
要点
  • 给出专业理由而不是现实理由：想在这个方向做得更深、本科阶段打的是基础、希望进入实验室做系统训练。
  • 可以提"希望在国内电子信息产业链上做事"这类与学校定位契合的动机。
  • 避免说"因为考研太难""因为家里希望"。
F2为什么选这个方向？（三个方向各自的回答思路）重点
要点
  • 新一代信息通信技术：从本科课程（信号与系统 / 通信原理）出发 → 讲一个让你觉得"有意思"的具体问题（如多径、编码）→ 说"想继续在这个方向做系统级的东西"。
  • 人工智能：从你的项目经历出发 → 讲你解决过的一个具体 AI 问题 → 说"想从调包走向理解模型本身"。
  • 集成电路：从"硬件是信息产业的底座"出发 → 结合你动手做过的电路/FPGA/器件实验 → 说"想做能落地的芯片方向"。
  • 通用结构：兴趣来源（真实经历）＋ 能力匹配（学过什么、做过什么）＋ 未来打算（想做哪类问题）。三句话缺一不可。
F3你的优点和缺点分别是什么？
要点
  • 优点：给带证据的（"做实验习惯先建基线，所以项目里返工少"），不要只说"努力认真"。
  • 缺点：说一个真实但不致命且你正在改进的，例如"我有时在细节上追求过度，导致进度慢，现在我会先设一个时间盒"。
  • 不要把优点包装成缺点（"我太追求完美了"这种回答老师听腻了）。
F4团队里出现分歧你怎么处理？
要点
  • 给真实小例子：技术路线分歧 → 用小实验/数据决定而不是争论 → 定下来后全力执行。
  • 落脚句："我倾向于先做最小验证，用数据说服彼此。"
  • 避免"我会听队长的"或"我不会和人吵"这类没有方法论的答案。
F5如果长时间做不出成果，你会怎么办？难点
要点
  • 这题在测抗压与科研耐力。分层回答：短期（复盘方法、缩小问题、找导师和师兄讨论）→ 中期（读文献看别人怎么做，必要时换技术路线）→ 长期（接受科研的试错本质）。
  • 避免两个极端：一是"我一定会坚持到底"，二是"不行就换题目"。
  • 可以引用你真实的失败经历作为证据（和 D8 呼应）。
F6如果导师给的课题你不感兴趣怎么办？
要点
  • 原则：先投入再判断。很多方向是"做进去才有兴趣"。
  • 如果确实不匹配，就先把手上的事做好，再找合适时机与导师沟通，看能否在课题框架内调整侧重。
  • 千万别答"我会直接换导师"——这在面试场合是负分。
F7工程硕博士要进企业实践 1–2 年，你怎么看？重点
要点
  • 这是工程硕博专项面试的必问题。官方《专业实践实施细则》明确：专业实践共 6 学分（工作计划 1 分 + 实践及总结报告 3 分 + 期满考核 2 分），实行工学交替模式，须进入签订联合培养协议的企业。
  • 正面回答：把入企实践视为优势——能接触真实工程问题、有企业导师、成果可以直接解决产业痛点，甚至可以用实践成果申请学位。
  • 可以举例："我知道学校有工程博士以实践成果替代学位论文、被《Nature》报道的案例，这正是我理解的工程硕博的价值。"
  • 要表现出对长期驻企业有心理准备，含糊其辞会被追问。
F8你愿意直博吗？
要点
  • 官方文件反复出现"鼓励优秀推免生报考直博生"。如果你有读博意愿，明确说愿意，并给出理由（想做长周期的研究问题）。
  • 如果不确定，诚实但积极："我目前更倾向先读硕士打好基础，如果研究进展顺利，我愿意继续读博。"
  • 不要为了录取随口答应直博——入学后反悔会有实际成本。
F9最后，你有什么问题要问我们？易错点
要点
  • 一定要准备 2 个问题，说"没有"会显得不重视。
  • 推荐问法：① "老师，如果我入学后想加入您的团队，您希望我在开学前先补哪些基础？" ② "这个方向目前最难突破的点在哪里？"
  • 不要问：能不能保证录取、奖学金多少、实验室累不累、能不能不去企业实践。

一周冲刺计划（9/10 – 9/15）

Sprint plan

目标：在 5 天内把「专业知识 + 项目讲述 + 英语开场」练到能脱稿。每天 4–5 小时，按下面的顺序做。

时间任务要点
今天 9/10（三） 确认报名状态 + 通读第 1、2、3 节 核对预报名截止时间与招生单位；把四个维度的权重关系看明白，定下主攻方向
9/11（四） 专业知识：把 A/B/C 里你方向的那一组过 2 遍 不要求全会，要求每题能说出 3 句话；标出完全不会的，明天专门补
9/12（五） 补漏 + 写项目讲稿 把 D1–D8 的答案写成你自己的话（一定要写下来，不要只在脑子里想）；录音回放 3 遍
9/13（六） 英语专项 + 综合素质 英语自我介绍 30 秒/2 分钟版本各练 10 遍；F1–F9 每题的立场想清楚，别临场编
9/14（日） 全流程模拟 2 次 严格计时 20 分钟：英语 3 分钟 → 专业 8 分钟 → 项目 6 分钟 → 综合 3 分钟。找人当老师提问，或对着录音
9/15（一） 面试当天：只看「没勾选」的题 + 材料 提前 40 分钟到场/上线；准备纸质材料、身份证学生证、成绩单、获奖与论文材料
🎯 冲刺期的三个取舍
  • 不要再花时间刷 GPA 或补竞赛——这两项在短期内无法改变。
  • 要把有限时间投到"能讲清楚"上：同样的经历，讲得清楚和讲不清楚，得分差一档。
  • 每天留 30 分钟把当天练的内容对着手机录一遍，这是提升最快的动作。

现场清单与红线

Checklist

面试材料清单（按各学院官方要求整理）

  • 本科阶段成绩单原件1 份，须加盖学校教务部门公章；通信工程学院还要求注明专业排名和专业总人数（前 5 或 6 个学期）。
  • 全国英语四、六级成绩单复印件，或 TOEFL、GRE/GMAT 等英语水平证明 1 份。
  • 其它能证明能力的材料：获奖证书、已发表或录用的学术论文、出版物或原创性工作成果。
  • 《西安电子科技大学推免生报考诚信承诺书》（本人亲笔签名）。
  • 身份证、学生证复印件；有条件的可附教授或导师推荐意见 2 份（通院通知中提到）。
  • 材料按顺序整合为 1 个 PDF，命名格式参考："预推免-学院-所在高校-本人姓名"。

面试现场要点

  • 20 分钟节奏：自我介绍 1–2 分钟 → 英语 3 分钟 → 专业 8 分钟 → 项目 5 分钟 → 综合 2 分钟。心里要有时间感，别在一个问题上耗太久。
  • 线上复试：提前测试摄像头、麦克风、网络，背景干净，光线从正面来；手边放好纸质材料和白纸笔。
  • 被问倒时的标准动作：先复述问题确认理解 → 说已知部分 → 承认边界 → 给出你会怎么去查。
  • 全程录音录像是官方规定，所以不要有侥幸心理，也不要说任何夸大或不实的内容。
  • 结束时对第 F9 题准备好两个提问。
⚠️ 五条红线（官方明确规定取消资格的情形）
  • 以虚报、隐瞒或伪造、涂改材料及其他欺诈手段取得录取资格。
  • 出现学术不端、不良诚信或违法违纪记录；论文抄袭、虚报获奖或科研成果。
  • 未参加复试、复试不合格，或思想政治素质和品德考核不合格。
  • 未通过"推免服务系统"完成报名、复试、录取。
  • 录取当年入学前未取得本科毕业证书。
